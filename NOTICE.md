## Origine

- [NTM-Continuum](https://github.com/Warfactory-Official/NTM-Continuum) : Golem et contributeurs.
- [HBM's Nuclear Tech Mod](https://github.com/HbmMods/Hbm-s-Nuclear-Tech-GIT) : HbmMods et contributeurs.
- [NTM: Space](https://github.com/Warfactory-Official/NTM-Continuum-Space) (GPL v3) : JamesH2, MellowArpeggiation et l'équipe NTM: Space ; HbMinecraft et l'équipe de HBM's Nuclear Tech Mod 1.7.10. Repris dans `space/structure` et `assets/geontm/structures/space` : structures des astres (bases de Mun, Minmus et Moho, relais de Duna, RBMK de Dres, artefact d'Ike, vertibirds de Laythe), placées sur les astres d'Ad Astra (`tools/importer_structures_espace.py`).
- Les autres crédits d'origine sont conservés dans les fichiers du projet.

La branche `upstream` garde le code d'origine sans modification. L'historique Git montre chaque changement apporté par Geoventure.

## Obligations à respecter

- Garder ces licences et ces crédits.
- Publier le code source de toute version distribuée aux joueurs, avec nos modifications.
- Garder le code repris de NTM dans ce dépôt : il ne doit pas être copié dans `geoMods`, publié sous MIT.
- Ne pas intégrer ici un mod dont la licence ne l'autorise pas. Voir le [plan](docs/PLAN.md#licences-des-autres-mods).
